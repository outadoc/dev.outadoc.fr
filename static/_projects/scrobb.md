There are quite a few Last.fm scrobblers out there, but this one is different.

Scrobb is based on the sources of the official Last.fm application. We only kept the bare minimum: the scrobbler. A few bugs which caused crashes were fixed, and the UI was updated for today's devices.

Which means that when the official app is able to scrobble something, Scrobb should be able to scrobble it too! It's more lightweight and more stable.

I also plan on adding a couple extra features in the future if I find out how. Please keep in mind that Scrobb is in no way associated with Last.fm, and you should still check out their official app if you want the complete experience!
