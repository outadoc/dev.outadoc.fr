Just a Twitter bot that listens for what you're saying. It will retweet every tweet mentionning him, and reply something random using [Yes That Can Be My Next Tweet](http://yes.thatcan.be/my/next/tweet). It's designed to imitate a targeted user to make a parody account, for example.

Follow the intructions on Github to configure it.
