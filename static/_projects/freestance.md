FreeStance is an iOS application that is designed to control your Freebox, a set-top box distributed by the French ISP _Free_, remotely.

FreeStance was my first iOS application, and I wanted it to be full of features in a nice interface so that it brings something more than the existing remotes. It was developped using Appcelerator Titanium.

FreeStance allows you to:

*   Control up to 3 different Freebox
*   Browse through the hundreds of available channels thanks to a simplified grid
*   Browse the TV guide and get info about what you're watching
*   Share the TV programs you like via Twitter, Facebook...
