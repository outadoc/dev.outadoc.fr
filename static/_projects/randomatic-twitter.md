Just a Twitter bot that listens for what you're saying. It will answer every tweet mentionning it something random it got from the previous tweets of the mentionner.

Begin by opening a new account for the bot on Twitter. Then, create an application for this account on dev.twitter.com, and get the API keys. Setup in apiKeys.json.

More info is available on Github.
