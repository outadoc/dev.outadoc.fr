**This API is now deprecated. Prefer using the [official API](https://gist.github.com/outadoc/40060db45c436977a912).**

This API provides real time info for the buses and trams of the Twisto network (operating in Caen, France) as JSON data.

It allows the user to retrieve lists of bus lines, directions and stops, and can then be used to fetch real time bus info for every stop.

More info on Github.
